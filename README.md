# 十六国 · 山河未定 — 3D 界面原型

依据《五胡十六国游戏3D界面设计方案》（设计版本 1.0）制作的**可玩网页原型**，
对应方案中「阶段一 界面骨架」+「阶段三 可玩闭环」的切片目标：
时代选择 → 战区 → 城池 → 军议 → 战斗 → 战报 六个关键页面完整走通。

## 运行

```bash
cd game
python server.py        # http://127.0.0.1:8765
```

或直接双击 `index.html`（无需服务器亦可运行）。

推荐 Chrome / Edge，1920×1080。

## 可玩流程（约 10 分钟）

1. **时代与剧本**：多轨时间轴（304—451，六条政权轨道并行）→ 秦统北方 → 淝水危局 → 东晋视角 → 进入。
2. **淮南战区**：滚轮缩放 / 中键拖拽 / Q·E 旋转 / Home 复位北向。点击寿阳（双击开城池详情）、渡口、八公山等节点；左栏地域树定位；右栏侦报/军议/军需。
3. **军议三案**：侦报面板「交叉核实」或军议页进入。方案 A 增派侦察 / B 改道行军 / C 掩护运输——点击方案只绘预览箭头，「拟为军令草案 → 明确下令」才入队。
4. **推进回合**：右下角按钮（悬停看执行预览）。结算演示行军、情报更新、粮耗与季节天气。
5. **渡口交锋**：护粮抵达渡口触发关键交锋。可**亲自指挥**（目标条 / 六单位部队栏 / 坚守·推进·护粮·转向·撤退·预备队 / 战术暂停与 0.5·1·2 倍速 / 侧边军情≤2条），或**委任将领**按同一战斗模型结算。
6. **战报与史鉴**：代价表、原方案假设对照（✓/✗）、史载·争议·本局推演三栏史鉴、人物史诗记录。关闭后返回原战区，世界状态已回写。
7. 继续回合经营：派斥候核实情报（纸雾消散、敌军以「估计」标记显现；情报一回合后自动转过时）、调整行军态势（快行/稳行/避敌，行军逐回合推进并真实到达）、委任边界、存档（自动存档 + 「继续上局」；待处理交锋与待阅战报随存档恢复，重复下令会被拒绝）。

## 技术说明

- 纯前端：Three.js r160（本地 `js/lib/`，无网络依赖）+ 原生 DOM 面板，经典脚本，无构建步骤。
- 地形程序化生成（确定性噪声），战场种子固定（`battleDukou.seed`），重载一致。
- 存档：localStorage（`shl-save-v1`），含未完成指令与已结算交锋标记。
- 提示音：WebAudio 合成（军令确认 / 新报 / 回合完成），可关闭。

## 已知边界（原型范围）

- 仅「淝水危局·东晋视角」一个可玩切片；其余章节为轨道占位与预告。
- 外交、人物史诗长线、多战区扩展为界面占位（按钮禁用并给出原因）。
- 数值与兵力为交互占位，不代表真实历史兵力与地理；正式制作需另行考据。
- 屏幕士兵数与真实兵力分开表示（军阵聚合棋子，不逐兵模拟）。
